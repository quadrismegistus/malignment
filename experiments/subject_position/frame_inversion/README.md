# frame_inversion

**id:** subject_position/frame_inversion **status:** OPEN. No producer. Stated 2026-09-04 from the tension recorded in the parent README.

# THE QUESTION

Templated, alignment raises the first person enormously. **Raw, alignment lowers it.**

On `neo`, whose rendered template is byte-identical at all three rungs — so the difference is not a template difference:

                            raw       chat
    neo_7b                0.0214    0.1375
    neo_7b_sft_v0.1       0.0090    0.4008
    neo_7b_instruct_v0.1  0.0059    0.7759

And in the refusal battery, conversational prompts: base 0.115 → SFT 0.071 raw.

Meanwhile **raw narrative interiority ROSE with alignment** (+0.224, 16/17, `passage_analysis/interiority_in_passages`, generated with no template — verified in the producers, which pass raw strings and never call `apply_chat_template`).

**So whatever the respondent training leaves in raw prose, it is not more first-person speech.** Outside the turn the model becomes *less* willing to say "I" while writing *more* inner life.

# THE TWO READINGS

1. **Two separate effects.** The turn-bound "I" and the prose interiority are unrelated consequences of alignment, and the inversion is a coincidence of measurement.
2. **The trace is not the pronoun.** What generalises from being trained to answer an Other is a capacity to represent inner states, not a habit of speaking as an I — in which case the raw interiority gain should be **third-person** interiority.

# THE NEAREST TEST

Whether the raw interiority gain is first-person or third-person interiority. **The interiority corpus is coded and on disk, so this is a query rather than a run.**

If third-person, reading (2) survives in a sharper form and the subject's thesis is refined rather than refuted.

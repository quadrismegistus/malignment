# Division of labour

**A SUBJECT, not an experiment.** It holds questions; it holds no code, no data
and no claims of its own. Anything shared between its questions belongs in
`malignment/`, not here — that rule is what keeps a second level from becoming
`meta/M01_displacement`, which was created empty, absorbed everything vaguely
related, and reached 250 scripts for 32 findings.

would be `k_01`…`k_47` under a nicer name: a variant nobody declared, whose
relationship to the first is knowable only by asking whoever ran it.

## Open, arising from `sft_share`

Each would be its own directory with its own registration, and **each must record
that it was run after seeing `sft_share`** — a follow-up chosen because the first
result disappointed is a specification search unless it says so.

- **`taboo_mapping/`** — does H3 survive with `taboo` (n=240) merged into
  `sexual` (n=157)? The mapping was fixed in `sft_share`'s registration *so that
  a null could not be converted by widening a category afterwards*. Running it is
  legitimate; running it and reporting only the merged version is not.
- **`domain_power/`** — at the observed effect (+0.0086 at base level), how many
  bases would be needed? A null at n=16 without a power statement is a number
  that cannot be distinguished from a small true effect.
- **`reversal/`** — `internlm2-chat-7b` had share **1.16**: its preference stage
  moved the model BACK toward base. SmolLM3's merge does the same at the endpoint
  (cumulative 0.1098 → 0.0909). Do preference stages ever undo SFT, and does it
  track the method? A separate question, not a caveat on this one.

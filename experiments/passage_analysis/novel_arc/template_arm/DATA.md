# Where TEMPLATE_ARM's data is

The design is `../TEMPLATE_ARM.md`; the code is this folder. The DATA is not in this repo (size, and Y's cells are sexual content): it lives under `$MALIGNMENT_DATA/template_arm/` (default `~/malignment-data/template_arm/`), with a manifest there -- `MANIFEST.md` and `manifest.json` (rows and sha256 of every file), written by `manifest.py`.

    passages.parquet               every generated passage (599,100: 606,800 declared, less
                                   rwkv-raven's 7,400 unsynced templated passages)
    coding/selection.parquet       what was coded for Figure 5 (31,831)
    coding/codings.parquet         the codings (narrative, mode, drift, degree, span, break)
    coding/journals/               raw coder output, one line per agent, per Workflow run
    calib/                         the coder-model calibration (CALIBRATION.md)
    pods/<pod>/<model>/<producer>/ the raw generation stashes as synced off each pod

The same stashes (all but the dropped RWKV lineage) are also in the canonical store, `$MALIGNMENT_DATA/generations/<model>/<producer>/`, so `Checkpoint(model).gen_stashes()` reads them with every other producer's passages; a template-arm passage is identified there by its seed (sha256(model|arm|stem)) and `render` (`ids_v2` for vLLM, `hf_batch` for the four HF lineages).

**How each piece was made**

| what | producer |
|---|---|
| prompts, exact as sent (per-condition n, seed) | `build.py` -> `prompts/` |
| generation, vLLM | `malignment/vllm_generate.py`, run by `fleet/box_ta.sh` on RunPod A40s |
| generation, HF (internlm2, recurrentgemma, Olmo-Hybrid; rwkv dropped) | `hf_batch.py` via `fleet/box_hf.sh` |
| passages.parquet | `collect.py` |
| coding draw | `triage.py` (passC's classifier, recovered) + `select_for_coding.py` |
| coder prompt, exact | `coding/ta_code_*.js` (passC rubric + `break`; claude-opus-5 pinned; generated by `coding/make_workflows.py`) |
| codings.parquet | `coding/harvest.py` over the Workflow journals |
| environment facts learned on the boxes | `roster/models/observations.json` |

Nothing here is on another machine or in ClickHouse yet.
